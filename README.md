# 🌦 Погода на завтра — бот и мини-приложение ВКонтакте

Проект из двух частей:

1. **`bot/`** — бот, который **каждый день автоматически публикует прогноз погоды на завтра** на стене вашей группы ВКонтакте.
2. **`miniapp/`** — **мини-приложение ВКонтакте** (VK Mini App): красивый прогноз на завтра и сегодня, выбор города, почасовой прогноз и кнопка «Поделиться». Запускается прямо внутри ВК.

Источник погоды — **Open-Meteo** (бесплатный, ключ API не нужен).

```
vk-weather-bot/
├── .github/
│   └── workflows/
│       └── weather-post.yml   # расписание автопостинга на GitHub Actions
├── bot/            # бот-постер (Node.js)
│   ├── index.js    # логика: погода + публикация + расписание
│   ├── .env.example  # шаблон настроек → скопировать в .env
│   └── package.json
├── miniapp/        # мини-приложение ВК (статические файлы)
│   ├── index.html
│   ├── app.js
│   └── style.css
├── install.bat     # установка зависимостей бота
├── test.bat        # показать пост без публикации
├── post-now.bat    # опубликовать пост прямо сейчас
├── start-bot.bat   # запустить бота по расписанию (локально)
└── README.md
```

Требования: **Node.js 18+** (у вас v22 — подходит).

## Часть 1. Бот (автопостинг в группу)

### Шаг 1. Получите ключ доступа группы

1. Откройте вашу группу → **Управление** (в правом меню).
2. Раздел **Работа с API** → вкладка **Ключи доступа** → **Создать новый**.
3. Отметьте право **«Работа со стеной» (wall)** → создайте и скопируйте токен.

### Шаг 2. Узнайте ID группы

- В адресе группы `vk.com/club123456789` ID — это `123456789`.
- Или: Управление → **Адрес**. Нужны только цифры, без минуса.

### Шаг 3. Настройте бота

1. Дважды кликните `install.bat` (установит зависимости).
2. В папке `bot` скопируйте `.env.example` в файл `.env` и заполните:

```ini
CITY=Москва        # ваш город
VK_GROUP_ID=123456789
VK_TOKEN=ваш_токен_из_шага_1
CRON=0 8 * * *     # каждый день в 08:00
# TZ_NAME=Europe/Moscow   # если нужно время не по компьютеру
```

### Шаг 4. Проверьте

| Файл / команда | Что делает |
|---|---|
| `test.bat` (или `npm test` в папке bot) | показывает текст поста в консоли, **ничего не публикует** |
| `post-now.bat` (или `npm run post:now`) | публикует пост на стене группы прямо сейчас |

### Шаг 5. Запуск по расписанию

**Вариант А — бот запущен постоянно (проще):**
дважды кликните `start-bot.bat` (или `npm start` в папке `bot`) и не закрывайте окно — пост будет выходить каждый день в 08:00 (по `CRON`).

**Вариант Б — Планировщик задач Windows** (окно держать не нужно, но компьютер в момент публикации должен быть включён):

Откройте «Командную строку от имени администратора» и выполните (пути поправьте под себя):

```
schtasks /Create /SC DAILY /ST 08:00 /TN "VK Weather Bot" /TR "C:\Users\Admin\Desktop\vk-weather-bot\post-now.bat"
```

**Вариант В — работает без вашего компьютера:** используйте GitHub Actions — подробная инструкция в разделе [«Автопостинг без компьютера»](#автопостинг-без-вашего-компьютера-github-actions-бесплатно) ниже.

> ⚠️ В вариантах А и Б пост выходит только если окно бота открыто (А) или компьютер в момент публикации включён (Б).
>
> ⚠️ Не запускайте одновременно локального бота и GitHub Actions — будут дубли постов.

## Автопостинг без компьютера: GitHub Actions (бесплатно)

Пост будет выходить на серверах GitHub по расписанию — ваш компьютер может быть выключен. Исходный код и секреты хранятся в **приватном** репозитории, токен в код не попадает.

### Шаг 1. Аккаунт и репозиторий

1. Если нет аккаунта — зарегистрируйтесь на [github.com/signup](https://github.com/signup).
2. Создайте репозиторий: [github.com/new](https://github.com/new)
   - имя: `vk-weather-bot`
   - видимость: **Private** (приватный!)
   - галочки «Add README», «.gitignore», «license» — **не** ставить
3. Загрузите проект. Git-репозиторий с коммитом уже создан, осталось выполнить в терминале (Git Bash), подставив свой логин:

```bash
cd ~/Desktop/vk-weather-bot
git remote add origin https://github.com/ВАШ_ЛОГИН/vk-weather-bot.git
git push -u origin main
```

### Шаг 2. Секреты репозитория

В репозитории на GitHub: **Settings → Secrets and variables → Actions → New repository secret**. Добавьте:

| Имя | Обязателен | Пример | Что это |
|---|---|---|---|
| `VK_TOKEN` | да | `adf1...` | ключ доступа группы с правом wall |
| `VK_GROUP_ID` | да | `123456789` | ID группы (только цифры) |
| `CITY` | нет | `Казань` | город (по умолчанию Москва) |
| `LAT` / `LON` | нет | `55.79` / `49.11` | координаты вместо города |

### Шаг 3. Проверка

Вкладка **Actions** → слева «Погода на завтра — автопостинг» → **Run workflow** → выберите режим:
- `test` — покажет прогноз в логе запуска, ничего не публикует;
- `post` — опубликует пост в группу.

### Шаг 4. Расписание

По умолчанию — **каждый день ровно в 19:00 по Москве**. Workflow запускается в 18:30 МСК (`30 15 * * *` UTC — не в начале часа, так меньше задержек GitHub Actions) и создаёт **отложенный пост** (`publish_date`), который ВКонтакте сам публикует точно в 19:00. Если GitHub сильно задержит запуск и после 19:00 — пост выйдет сразу, как workflow стартует. Чтобы изменить время выхода, поменяйте cron в `.github/workflows/weather-post.yml` (UTC = московское время − 3 часа, например 09:30 МСК = `30 6 * * *`) и `POST_TIME` в `bot/index.js` (по умолчанию 19:00). Запуски сильно раньше 19:00 (например, ночная задержка GitHub на несколько часов) просто пропускаются — пост выйдет в плановое время, без ночных постов и дублей. Если запуск случится уже после 19:00, пост публикуется сразу — лучше позже, чем никак.

Возможна задержка запуска до ~15–30 минут в часы пиковой нагрузки GitHub — для погодного поста это не критично.

### Несколько групп (несколько ботов)

Проект поддерживает до 5 групп одновременно. Все посты выходят по одному расписанию, у каждой группы — свой город и свой токен.

Чтобы добавить группу: в Secrets репозитория создайте секреты с суффиксом номера:

| Бот | Токен | ID группы | Город |
|---|---|---|---|
| 1 | `VK_TOKEN` | `VK_GROUP_ID` | `CITY` |
| 2 | `VK_TOKEN_2` | `VK_GROUP_ID_2` | `CITY_2` |
| 3–5 | `VK_TOKEN_3`…`_5` | `VK_GROUP_ID_3`…`_5` | `CITY_3`…`_5` |

Менять код не нужно: добавили секреты — бот подхватил новую группу при следующем запуске. Токен создаётся в каждой группе отдельно (Управление → Работа с API → Ключи доступа → право wall).

## Часть 2. Мини-приложение ВКонтакте

Приложение показывает прогноз на завтра и сегодня, позволяет менять город и делиться прогнозом через кнопку (стандартное окно «Запись на стене» ВК).

### Локальная проверка

Мини-приложение — обычные статические файлы. Для быстрой проверки можно просто открыть `miniapp/index.html` в браузере (вне ВК оно тоже работает, без VK-функций).

### Запуск внутри ВКонтакте (vk-tunnel)

1. Создайте приложение: [vk.com/apps?act=manage](https://vk.com/apps?act=manage) → **Создать** → тип **Mini App**, категория «Утилиты», отметьте платформы Mobile/Web.
2. В терминале:

```
cd Desktop\vk-weather-bot\miniapp
npx serve .                # поднимет локальный сервер на http://localhost:3000
```

во втором окне терминала:

```
npx @vkontakte/vk-tunnel --port=3000
```

3. vk-tunnel выдаст адрес вида `https://xxx.vk-tunnel.ru` — впишите его в настройках приложения ВК: **Управление → Настройки → Адрес приложения (iframe)** → Сохранить.
4. Откройте ваше приложение в ВК (Управление → «Перейти к приложению» или через поиск) — прогноз появится внутри ВКонтакте.

### Публикация на постоянку

- **VK Hosting (рекомендуется, бесплатно):** в настройках приложения ВК включите «Хостинг VK Apps», затем:

```
cd miniapp
npx @vkontakte/vk-hosting deploy
```

(запросит ID приложения и токен из настроек). После деплоя приложение работает в ВК без вашего компьютера.

- **Любой https-хостинг:** загрузите содержимое `miniapp/` (GitHub Pages, Netlify и т.п.) и укажите адрес в настройках приложения ВК.

## Частые вопросы

- **Ошибка VK API 15 / пост не выходит** — у токена нет права «Работа со стеной». Создайте новый токен с этим правом.
- **Ошибка VK API 5** — неверный `VK_TOKEN`.
- **Пост выходит дважды** — работают одновременно локальный бот и GitHub Actions. Оставьте что-то одно.
- **GitHub: «Не задан VK_TOKEN/VK_GROUP_ID»** — не добавлены секреты репозитория (Шаг 2 выше).
- **Город не найден** — проверьте написание или задайте в `.env`/секрете `CITY` координаты `LAT`/`LON`.
- **Как сменить город** — в боте: `CITY` в `bot/.env` или секрет `CITY` на GitHub; в мини-приложении: поле поиска города (сохраняется).
- **Сколько стоит** — ничего: Open-Meteo и GitHub Actions (приватный репозиторий, 1 запуск в день) бесплатны.
